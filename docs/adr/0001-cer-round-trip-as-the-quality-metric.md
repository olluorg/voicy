# ADR 0001. CER обратного распознавания как метрика качества озвучки

**Дата:** 2026-07-26
**Статус:** принято

## Контекст

Оценка «съедает буквы» / «звучит роботом» — впечатление. На нём нельзя
ни сравнить шесть движков, ни доказать, что правка помогла, ни автоматически
отбраковать сломанный файл из шестисот.

Отдельно обнаружилось, что дефекты бывают **беззвучными**: Silero молча
выбрасывает латиницу целиком. Фраза «Более безопасные варианты — ON DELETE
RESTRICT» звучала 1.7 секунды вместо ожидаемых 3.3 — SQL просто исчез.
На слух это не ошибка, а нормально прочитанное предложение; заметить можно
только сверив с исходником.

## Решение

Качество синтеза меряется **round-trip'ом**: синтез → распознавание через
Whisper large-v3-turbo → CER относительно исходного текста.

Нормализация перед сравнением: нижний регистр, `ё`→`е`, удаление пунктуации
и знаков ударения. Сравнивается произношение, а не орфография.

Этот же прогон становится **приёмкой в билд-скрипте**: файл с выбросом по CER
не публикуется.

## Обоснование

- Ловит все три класса дефектов разом: беззвучные выбросы, съеденные слоги,
  неверное произношение.
- Ровно то, чем меряет [Open TTS Leaderboard Ru](https://huggingface.co/spaces/ESpeech/open_tts_leaderboard_ru),
  то есть результаты сопоставимы с внешними.
- Дёшево: весь корпус на RTX 5080 проверяется примерно за час, разово.

## Последствия и ограничения

CER — прокси, а не истина. Whisper сам плохо распознаёт транслитерированные
термины: на образце про дженерики («Намбер», «Интеджер») CER завышен у **всех**
движков одинаково — Piper 4.0% против 1.3% на других образцах, Silero v5 14.3%
против 1.0%. Поэтому метрика достоверна **для сравнения вариантов на одном
тексте** и обманчива при сравнении разных текстов.

Практическое следствие: пороги приёмки задаются относительно медианы по корпусу,
а не абсолютным числом.

## Альтернатива, которую отвергли

Проверка длительности: сравнить фактическую длительность с ожидаемой по
символам и падать при расхождении. Ловит беззвучные выбросы, но слепа
к съеденным слогам и к неверному произношению. CER покрывает и это тоже
той же ценой.
