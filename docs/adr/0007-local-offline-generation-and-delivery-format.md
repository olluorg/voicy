# ADR 0007. Локальная офлайн-генерация, доставка в Opus по плейлистам

**Дата:** 2026-07-26
**Статус:** принято

## Контекст

Ограничение продукта, для которого делалось исследование: никакого бэкенда
и никаких провайдерских ключей на сервере. Плюс сценарий использования —
прогулка, то есть телефон с заблокированным экраном и, возможно, без сети.

## Решения

### Генерация — офлайн, на локальной машине

Скрипт запускается вручную, кладёт готовые файлы в статику. Сервер их только
раздаёт; ключей на нём нет по построению.

Проверенная скорость на RTX 5080 / Ryzen 9 7900X: ESpeech ×10, Piper ×40,
Silero ×65, Vosk ×2. Полный корпус (16.5 часов речи) — от 15 минут до 4.5 часов
в зависимости от движка и режима. Перегенерация после правки контента —
операция одного вечера, а не проект.

### Живой синтез в браузере — отвергнут как основной

`speechSynthesis` замолкает на Android при гаснущем экране, что убивает главный
сценарий. Остаётся запасным вариантом, когда файла нет.

### Формат — Opus 24 kbps моно

| Формат | Весь корпус | Один урок (~8 вопросов) |
|---|---|---|
| mp3 32 kbps | 238 МБ | ~3.2 МБ |
| **Opus 24 kbps** | **~119 МБ** | **~1.6 МБ** |

Вдвое меньше при лучшем качестве на речи. Продукт Chrome-first, поддержка
нативная.

### Доставка — ленивая, по плейлистам

119 МБ нельзя отдавать одним куском. Аудио грузится плейлистом (урок, слабые
места, дневная миссия) и кешируется через Cache API: скачал дома по wi-fi —
слушаешь офлайн.

## Последствия

- Имя файла содержит хеш исходного текста: устаревшая озвучка физически не может
  быть отдана, при несовпадении включается запасной путь.
- Инкрементальная перегенерация на первом этапе не нужна — проще перегенерировать
  всё.
