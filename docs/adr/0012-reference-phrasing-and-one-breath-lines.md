# ADR 0012. Референс отбирается ещё и по слитности, ключевые фразы — без внутренних запятых

**Дата:** 2026-07-26
**Статус:** принято (уточняет [ADR 0011](0011-reference-sets-the-rate.md))

## Контекст

Отзыв: фраза «И вот причина, ради которой этот вопрос и задают» читается кусками —
«И вот причина» / «ради которой этот вопрос» / «и задают», — хотя ожидается один вдох.

Реплика короткая (48 символов), внутреннему разбиению модели не подвергается.
Значит разрывы приходят из просодии.

## Диагноз

Замер разрывов **внутри** этой фразы, по всем шести референсам, в двух вариантах
пунктуации:

| Референс | с запятой | без запятой |
|---|---|---|
| Тургенев, «Поездка в Полесье» | 0 | 0 |
| Пушкин | 0 | 0 |
| Достоевский, «Записки из подполья» | 1 | 0 |
| Достоевский, «Белые ночи» | 2 | 0 |
| Лесков | 2 | 1 |
| **Тургенев, «Дворянское гнездо»** ← был выбран | **3** | 2 |

Три разрыва — [105, 355, 295 мс] — ровно четыре куска, в точности как описано в отзыве.

Причин две, и обе подтвердились:

1. **Референс выбирался по темпу и разборчивости, но не по слитности.** Замер
   собственных пауз в клипах показал, что выбранный чтец — самый рваный из всех
   медленных: 13.3 паузы в минуту и 15% тишины против нуля у трёх других.
2. **Запятая читается моделью как указание остановиться.** Её удаление снимает
   по разрыву у каждого референса.

## Ловушка: слитность нельзя оптимизировать в одиночку

Самый слитный чтец («Поездка в Полесье», 0 пауз в минуту) на полном тексте дал
**CER 18.8%** — слитно и неразборчиво. Второй по слитности — 14.1%.

То есть «слитный» и «разборчивый» — независимые свойства, и оптимизировать надо
их вместе, как до этого пришлось совмещать темп с разборчивостью.

## Решение

**Референс отбирается по трём измерениям сразу:** темп, плотность собственных
пауз, разборчивость на полном тексте. Выбран Достоевский, «Белые ночи»:
100 слов/мин, 9.1% тишины, CER 1.2%.

**Ключевые фразы пишутся без внутренних запятых.** Реплики типов `key`, `term`
и `question` короткие по построению и должны звучать на одном вдохе, поэтому
внутренняя пунктуация из аудио-версии убирается. Правило продолжает линию
[ADR 0010](0010-no-inserted-silence.md): пауза — свойство пунктуации, значит
отсутствие паузы тоже задаётся пунктуацией.

Затронуто 6 реплик из 26.

## Результат

| Вариант | слов/мин | пауз | тишины | CER |
|---|---|---|---|---|
| **сплошной синтез** | **102** | 21 | **1.7%** | **1.0%** |
| по репликам | 100 | 38 | 9.1% | 1.2% |

Побочное следствие: с хорошим референсом **сплошной синтез перестал проигрывать**
разбивке по репликам (1.0% против 1.2%) и оказался вдвое слитнее — 21 пауза
против 38. Вывод [ADR 0010](0010-no-inserted-silence.md) о превосходстве разбивки
был получен на плохом референсе и держался именно на нём.

## Конвейер после всех итераций

```
текст (объяснение, ключевые фразы без внутренних запятых)
  → синтез одним проходом с медленным слитным референсом
  → всё
```

Ни вставленных пауз, ни растяжения, ни разбивки, ни единого параметра,
подобранного на слух.
