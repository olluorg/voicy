# Синтез и распознавание речи

Репозиторий содержит локальный речевой сервер. Всё исполняется на машине
пользователя, ключи не нужны, в сеть ничего не уходит.

## Сначала — проверить сервер

```bash
./voicy status
```

Не отвечает — поднять: `./voicy up`. Команда ждёт готовности и прогревает
модели. **Первый запуск качает около пяти гигабайт весов и идёт долго**;
это не зависание. После каждого старта первый синтез дополнительно ждёт
загрузки модели в память.

Docker для этого не нужен: если его нет или он сломан, `up` сам переходит
на запуск из исходников. Не хватает зависимостей — CLI назовёт недостающие
и команды установки, а `./voicy up --source --install` поставит их в `.venv`.
Из исходников нужен ещё системный `ffmpeg`: без него синтезируйте в `wav`.

## Озвучить

```bash
./voicy say "Текст" out.opus
./voicy say @файл.md out.opus --voice dostoevsky --speed 0.9
```

Путь к файлу печатается в stdout. Голоса: `turgenev` (118 слов/мин, слитный,
по умолчанию), `dostoevsky` (100 слов/мин). Полный список — `./voicy voices`.

**Никогда не выводите аудио в stdout** — бинарные байты засоряют контекст.
Всегда указывайте файл, а при прямых вызовах curl — `-o`.

Длинный текст держите в файле и передавайте через `@`: так не нужно
экранировать кавычки и переводы строк.

## Распознать

```bash
./voicy hear запись.opus                # текст в stdout
./voicy hear запись.opus --format srt   # субтитры
./voicy hear запись.opus --words        # отметки времени по словам
```

## Если текст инженерный

Прежде чем звать синтез, перепишите текст в объяснение. Озвученный листинг
остаётся листингом: `List<? extends Number>` на слух не усваивается ни в каком
произношении. Короткие предложения без внутренней пунктуации слушаются лучше —
запятая читается моделью как повод остановиться.

Дальше помогают два флага, оба по умолчанию выключены:
`--prepare` применяет словарь произношений (79 терминов), `--legato` убирает
запятые внутри коротких фраз. Посмотреть результат без синтеза —
`./voicy prepare "текст"`.

Темп — `--speed` в диапазоне 0.8–1.2. Глубже становятся слышны артефакты
растяжения, которых метрика не показывает.

## Ударения

Qwen3-TTS обучался без разметки ударений и пользовательские знаки не понимает:
`+` он произносит вслух как «плюс», диакритика коверкает слово. Управлять
ударением можно только выбором слов — переписать омограф или поставить его
в однозначный контекст.

## Свой голос

```bash
./voicy add-voice образец.wav имя --note "чем хорош"
```

Образец — 8–14 секунд чистой записи, начало и конец на границе фразы.
Расшифровку не пишите руками: сервер распознает её сам, и это надёжнее.
