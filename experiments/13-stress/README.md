# 13 — ударения в Qwen3-TTS

**Вопрос:** можно ли управлять ударениями.

**Скрипты:** `scripts/stress_probe.py` (четыре нотации), `scripts/stress_probe2.py`
(нотации, не ломающие текст), `scripts/cer_stress.py`,
`scripts/stress_check.py` — **отрицательный результат, см. ниже**
**Замеры:** `results/results_stress.json`, `results_stress2.json`, `cer_stress.json`
**Аудио:** `article/assets/audio/stress__*`, `stress2__*`

## Исходное ограничение

Qwen3-TTS обучался без разметки ударений — это документированное ограничение,
по нему открыты обсуждения в репозитории модели.

## Что проверено

| Нотация | Результат | CER |
|---|---|---|
| `+` перед гласной | модель произносит «плюс» вслух | 22–64% |
| `́` U+0301 | коверкает слово: «стоюид», «Спив сок» | 7–26% |
| апостроф | ломается на длинных словах | 0–11% |
| **ЗАГЛАВНЫЕ** | **текст цел во всех случаях** | **0.0%** |
| переписывание слова | работает всегда, по построению | — |

Длительность от ЗАГЛАВНЫХ меняется (2.56→2.88 с, 3.60→4.00 с), то есть модель
на них реагирует. Двигает ли ударение в нужную сторону — решается ухом.

## Отрицательный результат: детектор ударений

Написана автоматическая проверка (границы слов из Whisper + энергетические ядра
внутри слова + ожидание из RUAccent). **Контроль провален**: на живой
человеческой записи, где ударения верны по определению, детектор показал 70%
расхождений, систематически смещённых к первому слогу.

Числа детектора нигде не используются, включая 61% на записи Qwen.
Скрипт сохранён как предупреждение.

Что помогло бы: фонемное выравнивание вместо энергетической эвристики.

## Рекомендация

Первый способ — переписывание: омографы в аудио-текст не попадают.
Второй — ЗАГЛАВНЫЕ точечно, с проверкой на слух.
