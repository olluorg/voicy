# 06 — модель пауз: длина принадлежит границе

**Вопрос:** почему паузы звучат неестественно и рвут фразу на полуслове.

**Скрипты:** `scripts/render_v3.py`, `scripts/cer_v3.py`
**Замеры:** `results/results_v3.json`
**Аудио:** `article/assets/audio/v3__*`

## Диагноз

Четыре источника тишины перемножились: сумма двух паддингов соседних реплик,
плюс явный `beat`, плюс глобальный множитель ×3, плюс растяжение всего файла
вместе с тишиной. 630 мс базовых превращались в 2055 мс.

| | Было | Стало |
|---|---|---|
| доля тишины | 33.8% | **12.3%** |
| медианная пауза | 2155 мс | **605 мс** |
| максимальная пауза | 9310 мс | 2915 мс |
| число пауз | 33 | 33 |

Расстановка пауз была верной изначально — неверными были длительности.

## Лестница темпа с новой моделью

| Вариант | слов/мин | тишины | CER |
|---|---|---|---|
| v3-1.00 | 137 | 6.8% | 4.8% |
| v3-0.88 | 122 | 6.1% | 4.5% |
| v3-0.82 | 114 | 5.7% | **2.2%** |
| v3-0.76 | 106 | 5.3% | 2.6% |
| **v3-0.70** | **98** | 4.9% | **3.9%** |

(проценты тишины здесь — только вставленные промежутки между репликами,
без учёта пауз, которые модель ставит внутри реплики)

Рекомендуется **v3-0.70**: 98 слов/мин внутри учебной нормы при CER 3.9%.
Если важнее чистота — v3-0.82 даёт лучший CER всего исследования, 2.2%,
но 114 слов/мин.
