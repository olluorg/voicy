# 25 — звук без ffmpeg

**Вопрос:** ffmpeg — единственное, что voicy просил поставить отдельно, и на
Windows его обычно нет. Можно ли кодировать и менять темп в самом процессе,
не потеряв в качестве.

**Код:** `rust/src/encode.rs` (opus, mp3, flac), `rust/src/tempo.rs` (темп).

**Ответ:** да. `wav`, `pcm`, `opus`, `mp3` и `flac` кодируются в процессе,
темп меняется своим WSOLA. За ffmpeg остался один `aac`. На машине без ffmpeg
(Windows) проверки идут 47 из 47 — столько же, сколько на Linux с ним.

## Форматы

libopus и LAME собираются в бинарник из исходников, flac — `flacenc` на Rust.
Настройки те же, что стояли в строке ffmpeg: opus 24 кбит/с, mp3 64 кбит/с,
flac по умолчанию. Одна фраза, 6.40 с звука, 24 кГц:

| формат | наш | ffmpeg | длительность |
|---|---|---|---|
| opus | 18 881 б | 19 110 б | 6.43 / 6.41 с |
| mp3 | 51 264 б | 51 885 б | 6.41 / 6.46 с |
| flac | 136 694 б | 145 293 б | 6.40 / 6.40 с |

Все три читаются сторонними средствами (`ffprobe`, распознавание), расшифровка
во всех форматах одна и та же. flac компактнее, потому что `flacenc` по
умолчанию сжимает сильнее, чем ffmpeg.

## Темп

WSOLA: звук нарезается окнами по 30 мс, и следующее окно берётся не строго по
расписанию, а там, где оно лучше всего совпадает с уже собранным хвостом
(поиск ±10 мс, нормированная корреляция). Растягивается готовый звук, а не
ручка модели: у модели замедление роняет разборчивость впятеро (ADR 0005).

Шесть фраз, сид 5, суммарно 33.70 с в норме. CER — обратным распознаванием.

| скорость | длительность наша | ffmpeg | ожидалось | CER наш | CER ffmpeg |
|---|---|---|---|---|---|
| 0.8 | 33.70 с | 33.58 с | 33.70 с | 0.23% | 0.23% |
| 1.2 | 22.47 с | 22.49 с | 22.47 с | 0.23% | 0.23% |

Без растяжения CER тех же фраз — 0.23%: растяжение в этих границах не портит
разборчивость ни у нас, ни у ffmpeg.

CER не слышит щелчков на стыках окон, поэтому отдельно посчитаны резкие скачки
между соседними отсчётами (больше 8×RMS):

| | резких скачков | худший скачок |
|---|---|---|
| без растяжения | 0 | 3.8×RMS |
| 0.8 наша / ffmpeg | 0 / 0 | 3.8 / 3.8×RMS |
| 1.2 наша / ffmpeg | 0 / 0 | 3.5 / 3.8×RMS |

## Что пришлось учесть

- **libopus собирается через CMake**, а он объявляет совместимость с CMake 3.1,
  которую CMake 4 больше не принимает. `rust/.cargo/config.toml` просит вести
  себя как раньше — иначе сборка на Windows падает.
- **Ogg Opus считает время в отсчётах 48 кГц** независимо от частоты входа,
  и в заголовке нужен pre-skip — задержка кодировщика, которую проигрыватель
  обрежет. Без него звук начинался бы на несколько миллисекунд раньше.
- **`aac` оставлен ffmpeg**: свободного кодировщика той же выделки нет,
  а формат в voicy почти не используется.

## Вывод

Из внешних зависимостей у бинарника остались только системный `ffmpeg` для
`aac` и видеодрайвер. Для всего остального — включая формат по умолчанию —
достаточно самого файла.
