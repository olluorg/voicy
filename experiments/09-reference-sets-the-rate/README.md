# 09 — темп берётся из референса

**Вопрос:** можно ли получить нужный темп без искусственного растяжения.

**Скрипты:** `scripts/cutrefs.py` (нарезка по границам фраз), `scripts/render_v8.py`
**Замеры:** `results/results_v8.json`, `results_cdg.json`, `results_cnu.json`
**Данные:** `data/reference_texts_clean.json`
**Аудио:** `article/assets/audio/ref__*`, сами клипы — `refclip__*`

## Две ошибки

1. Референс отбирался только по CER. Его темп ни разу не измерялся — а F5
   копирует из референса и темп тоже. Взят один из самых быстрых чтецов
   (121 слов/мин), следствие лечилось растяжением ×0.66.

2. Клипы резались фиксированным окном по таймеру, попадая в середину фразы.
   Транскрипт получался обрубком, а F5 использует его дословно — портится
   каждый синтезируемый сегмент.

## Результаты

| Референс | нарезка | растяжение | слов/мин | пауз | CER |
|---|---|---|---|---|---|
| Лесков | по таймеру | ×0.66 | 97 | 35 | 3.2% |
| Тургенев | по таймеру | ×1.00 | 108 | 136 | 7.3% |
| Тургенев | по таймеру | ×0.92 | 100 | 153 | 7.5% |
| **Тургенев** | **по фразам** | **×1.00** | **91** | **142** | **1.0%** |
| Достоевский | по фразам | ×1.00 | 133 | 27 | 11.2% |

Чистая нарезка того же клипа дала **7.3% → 1.0%**, семикратное улучшение.

## Итог

**CER 1.0% при 91 слове в минуту, без растяжения и без вставленных пауз** —
лучший результат исследования.

Конвейер сократился до: текст → реплики → синтез → склейка встык.
Ни одного параметра, подкрученного на слух.
