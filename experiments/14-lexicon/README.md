# 14 — словарь произношений

**Вопрос:** как произносить термины, у которых нет синонима того же регистра.

**Скрипты:** `scripts/probe_english.py` (латиница против кириллицы),
`scripts/probe_generics.py` (семь написаний одного термина),
`scripts/render_lexicon.py` (озвучка словаря пачками)
**Данные:** `data/pronunciation.json`
**Замеры:** `results/results_english.json`, `results_generics.json`, `results_lexicon.json`
**Аудио:** `article/assets/audio/lexicon__batch*`, `english__*`, `generics__*`

## Почему словарь, а не общее правило

Переписывание из [ADR 0015](../../docs/adr/0015-stress-control-in-qwen3-tts.md)
работает только там, где есть синоним того же регистра. «Дженерики» → «обобщения»
чинит озвучку ценой профессиональной лексики.

## Что проверено на «дженерики»

Семь написаний, у каждого замерена доля энергии по четвертям слова:

| Написание | Пик энергии | Вывод |
|---|---|---|
| Дженерики | 3-я четверть, 81.0% | как сейчас |
| ДЖЕнерики | 3-я четверть, 82.5% | **ЗАГЛАВНЫЕ ударение не двигают** |
| ДженЕрики | 3-я четверть, 86.1% | то же |
| Generics | 3-я четверть, 89.0% | услышано как «Генерикс», теряется «дж» |

Ни одна внутритекстовая уловка ударение не переносит.

## Латиница в русской фразе — нестабильна

| Термин латиницей | Что услышал Whisper |
|---|---|
| `Generics` | «Генерикс» — потеряно «дж» |
| `Wildcard` | «Валдгад» — смазано |
| `Integer` | `Integer` — распознан как английский, чисто |
| `type erasure` | «тип и резерв» — развалилось |
| `Generics … wildcard` в одной фразе | оба распознаны латиницей — прочитаны внятно |

Одно и то же слово читается по-разному в зависимости от фразы. Управлять этим
нельзя, поэтому политика словаря — кириллица.

Побочно: кириллическая «Интеджер» распозналась **как английское `integer`** —
то есть транслитерация даёт верное английское чтение надёжнее латиницы.

## Словарь

79 терминов с частотой 8+ в корпусе, три группы: аббревиатуры (28),
имена классов (26), остальное (25). SQL-ключевые слова в словарь не входят —
в аудио они переводятся смыслом.

Озвучены пачками по 10: **8 клипов, 93 секунды на всю проверку**.
Поле `verified` проставляется после прослушивания.
