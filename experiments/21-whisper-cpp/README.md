# 21 — распознавание без Python: whisper.cpp против faster-whisper

**Вопрос:** можно ли заменить faster-whisper на whisper.cpp, чтобы сервер работал
совсем без Python, не потеряв в качестве.

**Код:** `rust/src/native/whisper.rs` — whisper.cpp b5130 через C API
**Ответ:** нет. По скорости не хуже, по точности хуже там, где voicy мерится.
По умолчанию остаётся faster-whisper; whisper.cpp — по `STT_ENGINE=whisper.cpp`.

## Почему whisper.cpp

faster-whisper стоит на CTranslate2 — библиотеке на C++ без C API, и связать её с
Rust без компилятора C++ нельзя. whisper.cpp — та же модель large-v3-turbo на
ggml, с C API и готовыми сборками; под Linux готовая сборка только для
процессора, но CUDA-бэкенд берётся из llama.cpp b11090 — ggml у них общий,
и связка работает.

## Замеры

RTX 3080. Обе стороны с одинаковыми настройками там, где они есть у обеих:
large-v3-turbo, лучевой поиск на 5, язык ru, неречевые токены подавлены.

| | faster-whisper | whisper.cpp |
|---|---|---|
| 5 минут синтезированной речи | 5.7 с | 4.9 с |
| 30 фраз синтеза + 2 живые записи, CER | 1.97% | 1.97% |
| те же фразы, синтез Rust-движком, CER | 2.1% | 2.3–2.4% |
| **Golos crowd, 298 живых фраз, CER** | **10.4%** | **12.8%** |
| **термины без контекста** | **65.7%** | **57–60%** |
| **термины с подсказкой** | **68.6%** | **65.7%** |
| **термины с hotwords** | **82.9%** | **71–74%** |
| **термины с подсказкой и hotwords** | **85.7%** | **71–74%** |

Термины — `scripts/context_eval.py` (experiments/16), те же 20 фраз на тех же файлах.

## Что пробовали

- **Без повтора при срыве**, как у faster-whisper в voicy: лучевой поиск
  whisper.cpp иногда зацикливается на первом слове («распознавание
  распознавание распознавание…»). С повтором (шаг температуры 0.2) — нет.
- **Состояние между запросами.** whisper.cpp держит прошлый текст в состоянии
  контекста между вызовами: без `no_context` расшифровка прошлого запроса
  становится подсказкой следующему, а своя подсказка вытесняется. Именно это
  давало обманчиво хорошие 9.9% на Golos — короткие команды подсказывали друг
  другу. С `no_context` каждый запрос начинается с чистого листа; внутри файла
  окна по-прежнему видят свой предыдущий текст.
- **Без подавления неречевых токенов, без повтора, жадный поиск** — термины
  60–77%, до faster-whisper не дотягивает ничего.
- **Детектор голоса перед файлами** — против галлюцинаций на тишине («Редактор
  субтитров А.Семкин…»): Golos 12.85%, термины 71%. Не помог.

Раскладка `whisper_full_params` проверена: смещения полей сверены с
заголовком b5130, скомпилированным gcc (тест `layout_matches_whisper_h`).

## Вывод

whisper.cpp быстрее на 15%, но на живой речи ошибается на 2.4 п.п. чаще, а
инженерные термины — главное, ради чего в voicy контексты, — узнаёт в 71–74%
случаев против 83–86%. Это регресс, и по умолчанию его нет.

Цена: сервер на Rust по умолчанию запускает Python-процесс ради одного
распознавания. Синтез, детектор голоса и конец реплики — без Python.

Что может закрыть разрыв: CTranslate2 из Rust (нужен компилятор C++ для
обёртки над его C++ API), либо ONNX-экспорт Whisper с логикой декодирования
faster-whisper поверх ONNX Runtime. Оба пути — отдельная работа с тем же
порогом: не хуже faster-whisper ни на Golos, ни на терминах.
