# 03 — лечение артикуляции

**Вопрос:** можно ли сохранить подачу ESpeech и убрать «съеденные буквы».

**Скрипты:** `scripts/sweep.py`, `scripts/human_ref.py`, `scripts/final_run.py`,
`scripts/measure_cer.py`, `scripts/transcribe_refs.py`, `scripts/mkref2.py`
**Замеры:** `results/results_sweep.json`, `results/results_human.json`,
`results/results_final.json`, `results/cer.json`, `results/cer_final.json`

## Что проверялось

| Рычаг | Эффект |
|---|---|
| RL-V2 вместо PODCASTER | **вдвое лучше** (25.3→10.5, 16.8→7.1, 17.5→10.0) |
| человеческий референс вместо синтетического | разброс 2.8–21.9% между шестью чтецами |
| nfe 32 → 64 | без эффекта, время ×2 → остановились на 48 |
| скорость 0.9 | помогает не всегда, зависит от референса |
| Vosk как донор артикуляции | **не сработало**, 10–12% |

## Итог

~20% → 4.6–9.2% CER. Референс оказался главной настройкой модели, а не
косметикой, и подбирается замером.
